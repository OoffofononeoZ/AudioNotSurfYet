# Visualizer 组合工作区

核查日期：2026-10-20。当前[Project V5](../architecture/visualizer/project-format-v5.md)和[可执行资源包V2](../architecture/visualizer/resource-packages-v2.md)管理元素、算法/Shader、分组预设及共同处理参数，接口见[页面契约](../architecture/visualizer/interface-contracts.md)。

## 当前布局与模型

- 普通页保留MusicBar；顶部工程/Settings，左侧资源与元素/组列表，右侧选择属性，中央零padding视频，底栏输出/Editor/状态。可用宽度决定三栏或互斥抽屉，页面保持单100dvh与独立滚动。
- 预设为默认折叠顶层组，顶层移动整组、组内排序；共同处理参数批量写入且提示差异，不提供全局数字layer编辑。既有算法及预设见[预设说明](visualizer-presets.md)，新增内容按外部skill自主生成，正常交付附实际展示图。
- 效果引用视觉元素或整体，不引用其他效果；显式同歌单range转场保持终值，由后开始转场接管。单renderer/Canvas/视觉RAF、三个复用targets、绝对歌曲时间和四Analyzer特征边界保持。
- ABI 2 元素可声明点/范围输入，属性区选择轨道、分类和单个事件或集合；绑定只写当前 V5 工程。集合查询按窗口分页，合法空集合可运行；缺失引用拒绝快照替换，启用但未绑定阻止导出。淡入淡出现使用单范围标记接口，插值、终值及重叠接管保持，旧工程仍使用自身算法快照。
- 只接受V5文件；旧草稿不提示、不迁移。损坏/异歌V5草稿、保存失败和换歌取消按当前草稿保护。商城只读加载用户选择的 assets 文件夹，提供选择/恢复访问/重新加载；未连接库时列表使用通用标记；工程导入验证期间锁定编辑并标记忙碌，验证成功后原子替换。
- 全屏只显示同一画面、图标控制/时间/进度，无MusicBar；视频导出与全屏互斥。输出采用[离线导出](visualizer-offline-export.md)，不恢复旧实时capture链。

## 界面控件

资源商城使用固定头尾与独立滚动资源区，最大宽度 1080px、目标高度 76dvh、最小高度 620px，按视口可用空间收缩；单行、空结果及加载状态不改变尺寸。元素/预设独立切换，搜索名称与描述，元素按类型、预设按用途筛选，切换类型清空不适用筛选。网格按可用宽度显示三/二/一列，复用 app-scrollbar，仅实际溢出时展示滚动条。

卡片使用 16:9 完整图片、名称、必要描述、创建者 default 及真实创建日期；相同标题和描述不重复展示。封面支持及缺失处理见[资源包 V2](../architecture/visualizer/resource-packages-v2.md)。首次使用显示“加载资源库”，连接后底栏展示文件夹/数量、更换和刷新；权限恢复、失败和无法记住文件夹分别反馈。关闭商城不释放页面资源库，取消/失败重载保留当前库；点击卡片或键盘确认沿用精确资源身份添加并关闭。

元素列表每行始终显示上移、下移、显示/隐藏和删除操作，并为操作预留固定高度。操作未选中元素不改变当前选择；顶部/底部移动边界、拖拽及导出锁保持原有规则。

输出底栏及元素属性统一使用通用 AppSelect/AppNumberInput。下拉菜单在当前 Chrome/Edge 使用可定制原生 picker，保持键盘选择、取消和焦点，只有内容超过最大高度时显示滚动条且不预留空白轨道；数值输入使用自有步进按钮，提交有限数值并遵守 min/max，导出锁传入全部控件。AnimatedList 的方向键只在列表内获得焦点时处理，Tab 使用正常焦点顺序。

输出尺寸、帧率及码率接入[离线确定性导出](visualizer-offline-export.md)。底栏与预检共用实际编码能力查询，四档独立选择，导入设置保留、不自动降档。旧静态禁用表和首录掉帧提示已退役；历史实时录制测量仍见[输出质量说明](visualizer-output.md)。

底栏分析状态、百分比、特征数量、导出状态及帧进度统一位于页签切换行末尾、“已保存”之前，切页签及折叠后仍显示。状态摘要空间不足时只在自身横向滚动，复用 app-scrollbar 并支持键盘；保存状态与折叠按钮保持可见。状态页保留错误详情、重试、保存/丢弃 WebM，不重复摘要。进度更新不重新展开面板；出现新错误或待处理 WebM 时打开状态页。

全屏进度条由 AppPlaybackProgress 展示，与 MusicBar 共用 playbackProgress.css 的 5px 灰色轨道、绿色渐变和白色圆点；保留原有音频命令和同一 Canvas。已有草稿使用 VisualizerDraftNotice 卡片，只显示一行标题，不区分版本文案；导出、明确覆盖和取消语义保持不变。

### 属性数值编辑

`SceneNumericRange.editingPrecision` 是字段的 UI 元数据，不进入工程格式，也不从当前输入值推断。整数步长为 1；普通小数精度为 2、步长 0.1；精度 ≥3 时步长为 `10^-(precision-1)`。

| 字段意义                                              | 声明精度 | 步长   |
| ----------------------------------------------------- | -------- | ------ |
| 层级、数量、形状、重复次数、Bin/频段索引              | 0        | 1      |
| 系数、透明度、角度/相位、像素尺寸/线宽                | 2        | 0.1    |
| 秒数、速度、归一化位置和宽高                          | 3        | 0.01   |
| 归一化半径、填色阈值                                  | 4        | 0.001  |
| 微小几何尺寸、径向间距、游移/光轨长度、归一化位移幅度 | 5        | 0.0001 |

映射输出上下限继承目标字段精度，输入上下限使用精度 2，起音/释放秒数使用精度 3。新元素与预设的视觉常量按声明精度取值，载入的工程、草稿和歌曲原始时长不量化。

属性数值输入的上下按钮、键盘方向键与鼠标滚轮共用步进：从当前输入加减固定步长，按字段精度消除浮点尾数并限制 min/max；时间、频段及映射输入范围不能因步进倒置或合并。手动输入仍沿用原有有限值及工程校验。滚轮悬停即可调整，每个非零垂直事件一步、不加速，范围边界仍消费事件，避免带动属性栏；Ctrl/Meta 与纯横向事件不截获。显式/fieldset 禁用时不调整。只为属性区启用滚轮，输出底栏 Seed 保持原交互。

MusicBar 右侧由 MusicBarActions/MusicBarIcon 展示，六个按钮统一 32px 点击区、20px 图标及 1.6px 描边；窄屏点击区统一 28px。样式切换使用叠放播放器布局图标，播放模式仍使用顺序/单曲/列表/随机图形；旧右侧 sprite 符号移除，导航与 transport 图标继续保留。

## Analyzer 输入

Buffer 的 compact payload 只保存时间桶的最小/最大值，不能作为完整波形向量。当前从已有 AudioEngine 的 decoded copy port 按绝对歌曲时间读取 1024 点帧，沿用 Analyzer 的 512 hop、average-mono、Hanning 窗和尾部补零；不插值两个波形帧，不新增音频上下文或逐帧 Worker 请求。最多缓存 16 帧，按曲目与 decoded revision 隔离，离页/释放租约时清理；缺少完整波形时明确报错，不退回包络。Inspector 和工程校验的 Buffer Bin/范围上限同步为 1024 点。

完整向量未配置显式数值变换时，先适配为视觉强度，再交给隔离算法：Buffer 取绝对值、Chroma 使用非负值，二者的单位幅度换算到既有 128 参考；Power Spectrum 开平方还原振幅；MFCC 取绝对值，避免负系数被直接截成零。Amplitude Spectrum、Loudness specific、Complex magnitude 保留既有参考和维度。标量及 mean/max/peak/bin/band 投影保留原始单位和符号，继续由数值映射控制；Complex phase 的时间插值沿圆周最短路径跨越 ±π。当前V5 strict字段和Analyzer缓存格式以现行契约为准，不使用旧Buffer两端点策略。

## 播放策略

顺序播放为新默认，到队尾停止；列表循环首尾衔接；随机播放每轮避免重复，上一首回到历史。Visualizer 与 Editor 的 route lease 都覆盖为单曲循环，不持久化覆盖值；Visualizer 直接列表选歌先处理工程覆盖；选歌后播放，取消时不切歌、不改工程。

导出准备、进行及收尾阶段锁定工程；取得独占 transport 后暂停播放并锁定公开播放、seek、换歌、导入与清理命令，音量不锁定。租约在资源清理时释放，恢复仍匹配的播放检查点。普通播放的结束边沿仍仅消费一次，不能由音量等快照重发触发重复结束处理。
