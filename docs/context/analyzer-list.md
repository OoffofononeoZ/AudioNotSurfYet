# Analyzer 单列列表与置顶分析区

本页是 DEC-077 的当前界面契约，替代 M12 双列 masonry 和 M14 手动排序交互。既有 canonical/readiness 继续绑定历史候选，日常验证不改写正式证据。

## 布局与高度

- 始终单列，行无卡片外框、圆角和投影；分隔线沿用旧 Header 的 1px 两端透明主题色渐变线。行内容左右使用 `clamp(16px, 4%, 64px)` 内缩，让标题、说明、图表与右侧开关靠近横线可见范围，分隔线仍贯穿整行。
- 顶部 64px 留白避开 Settings/窄屏导航，底部沿用 150px MusicBar 安全空间；状态、数量、持久化失败和错误/重试保留。
- 顶部分析区常驻，原列表独立滚动，两者复用 `.app-scrollbar`；没有活动分析时隐藏置顶区和手柄。
- 高度按状态区下方、播放器安全空间上方的可用工作区计算。初始为自然内容高度（含24px手柄）与可用高度60%的较小值。
- 手柄下限40%，上限为自然内容高度与工作区满高的较小值；内容不足40%时自然高度优先，手柄禁用，不制造空白。
- 用户比例只在当前页面会话保留，内容/details/说明/窗口变化后重新裁剪实际高度；内容再次增加时仍采用原用户比例。
- 满高时原列表为零高度并设为 inert，拖小后恢复滚动位置；手柄始终留在安全空间内。
- 指针捕获支持鼠标/触控；上下键每次5%，Home/End到边界。Escape、pointercancel、lost capture或blur取消拖动并恢复起始比例。

## 行与活动队列

- 原列表按 `FEATURE_IDS` 排列并排除活动项；顶部按 `activeFeatureQueue` 倒序显示，最新项在最前。
- 队列自身仍按最早到最新保存，最多四项、唯一且原子更新；第五项淘汰队首并归位，主动收起同样归位，重新展开刷新年龄。
- 行转移保持原列表第一个仍可见非移动项的阅读锚点；新展开仅将置顶区滚至开头。焦点使用 preventScroll 恢复，满高时留在可见开关/手柄。
- 标题与说明原文不改写。分析开关只显示chevron；说明独立默认单行、省略溢出，仅实际多行时显示前置开关，展开显示全文。
- 说明展开不触发分析或改变队列，状态按feature ID存于页面，行转移保留，重新进入收起；宽度和字体变化重新测量。
- 未转移的活动行不重建组件/表格；收起或淘汰释放图表，精确值details下次默认关闭。分析仍复用单consumer/job。

## 区间与保存

- 删除共享视口工具栏、pan/zoom/reset、手动排序及恢复默认排序入口。
- 仅图表绘图区内纵向滚轮缩放，以鼠标x对应时间为锚点，上滚1.12倍、下滚反向，范围1–64；边界处不滚动外层。
- Ctrl/Meta保留浏览器行为，图表之外正常滚动；所有图表完整同步start/end/zoom，点击和键盘定位播放继续保留。
- 高频wheel即时更新图表，持久化按RAF合并最新区间；换歌取消旧待保存区间，离页保存当前有效区间。既有revision/generation/cache隔离不变。
- V1 会话 carrier 保留，Analyzer 使用 `analyzerWorkspaceVersion:2`。移除旧排序字段和校验；旧工作区清空活动项、视口与分析缓存并写回，歌曲队列、句柄及独立草稿保留。列表只按 FEATURE_IDS 排列。
- 高度/说明不新增持久化字段，队列与区间继续恢复；Canvas renderer、音频时间基准、Editor/Visualizer接口不变。Observer、RAF、监听和指针捕获按所属组件释放。

## 验证

`test:m12:unit`现覆盖高度模型，`test:m14:unit`验证定义顺序与邻接队列/区间。浏览器沿用M12/M13/M14命令名称，当前分别覆盖单列/说明/资源、FIFO/恢复、置顶/锚点/手柄/滚轮；历史命令名不代表旧交互仍存在。

2026-10-13：高度、FIFO、区间与会话专项30项通过；Chrome/Edge各7项本轮浏览器回归通过，覆盖390/1024/1280/1920、第五项淘汰、刷新、同步缩放、高度边界和十次路由资源释放。此记录不是正式canonical或发布批准。

精确值组件约500行，仅承担数值的格式与DOM表格呈现，无异步任务或浏览器资源所有权；图表、说明测量和页面调度已独立拆分。本轮保留这一完整呈现职责。新增首项[Wallpaper Engine 风格频谱](wallpaper-spectrum.md)使用独立双声道 Canvas 绘制模块，保留现有 Meyda 数值链路。
