# Analyzer 单列列表与置顶分析区

本页是 DEC-077 的当前界面契约，替代 M12 双列 masonry 和 M14 手动排序交互。既有 canonical/readiness 继续绑定历史候选，日常验证不改写正式证据。

## 布局与高度

- 始终单列，行无卡片外框、圆角和投影；分隔线沿用旧 Header 的 1px 两端透明主题色渐变线。行内容左右使用 `clamp(16px, 4%, 64px)` 内缩，让标题、说明、图表与右侧开关靠近横线可见范围，分隔线仍贯穿整行。
- 顶部 64px 留白避开 Settings/窄屏导航，底部沿用 150px MusicBar 安全空间；状态、数量、持久化失败和错误/重试保留。
- 顶部分析区常驻，原列表独立滚动，两者复用 `.app-scrollbar`；没有活动分析时隐藏置顶区和手柄。
- 高度按状态区下方、播放器安全空间上方的可用工作区计算。初始为自然内容高度（含24px手柄）与可用高度60%的较小值。
- 手柄下限40%，上限为自然内容高度与工作区满高的较小值；内容不足40%时自然高度优先，手柄禁用，不制造空白。
- 用户比例只在当前页面会话保留，内容/details/说明/窗口变化后重新裁剪实际高度；内容再次增加时仍采用原用户比例。
- 满高时原列表为零高度并设为 inert，拖小后恢复滚动位置；手柄始终留在安全空间内。
- 指针捕获支持鼠标/触控；上下键每次5%，Home/End到边界。Escape、pointercancel、lost capture或blur取消拖动并恢复起始比例。

## 行与活动队列

- 顶部 Settings 预留行提供原曲、原曲（3d图表）及已验证四轨来源切换；未完成分离时隐藏四轨。2D 各来源独立保存最多四项 FIFO 置顶队列，分轨仅有 Wallpaper 频谱、energy、幅度谱、buffer；只请求当前模式/来源活动项，共用时间视口，不切换试听。来源与队列随 V1 会话的可选 analysisSources 保存，原曲 activeCards 保持原有含义。

- 原列表按 `FEATURE_IDS` 排列并排除活动项；顶部按 `activeFeatureQueue` 倒序显示，最新项在最前。
- 队列自身仍按最早到最新保存，最多四项、唯一且原子更新；第五项淘汰队首并归位，主动收起同样归位，重新展开刷新年龄。
- 行转移保持原列表第一个仍可见非移动项的阅读锚点；新展开仅将置顶区滚至开头。焦点使用 preventScroll 恢复，满高时留在可见开关/手柄。
- 标题与说明原文不改写。分析开关只显示chevron；说明独立默认单行、省略溢出，仅实际多行时显示前置开关，展开显示全文。
- 说明展开不触发分析或改变队列，状态按feature ID存于页面，行转移保留，重新进入收起；宽度和字体变化重新测量。
- 未转移的活动行不重建组件/表格；收起或淘汰释放图表，精确值details下次默认关闭。分析仍复用单consumer/job。

## 原曲 3D（DEC-113）

- 只列 Wallpaper 频谱、幅度谱、功率谱、Chroma、响度、MFCC 和复数谱，最多一项；选择新项原子替换，收起后不请求分析。首次进入为空，原曲 2D 与四轨队列独立保留。
- 时间/数值/分量构成立体曲面；Wallpaper 按左 64、右 64 排列，Chroma 保留音级，MFCC 保留负值。响度 total 在 24 个 specific 频带外留出间隔单独成线；复数谱可选幅度/相位，保留全部 FFT bin 与有符号频率，相位跨 ±π 不连线。
- 左键拖动屏幕平移，右键绕图表中心旋转，拖动不 seek；右上角加减控制相机观看比例。滚轮独立使用既有 1.12 倍、1–64 时间视口规则，按当前投影定位时间；Ctrl/Meta 保留浏览器行为。
- 伪 2D 用正交相机对齐时间—数值面，只画所选原始分量；最左侧轴的箭头支持点击、拖动、方向键/PageUp/PageDown/Home/End，数值输入可直达索引。返回 3D 恢复之前的平移/旋转/相机比例；切片与姿态不持久化。
- V1 的可选 `analysisPresentation` 保存原曲模式和 3D 单项，刷新/离页恢复，不覆盖 `activeCards`；缺省维持 2D，工作区/分析缓存版本不变。换歌重建图表，取消或迟到网格不得覆盖当前数据。
- DEC-116：整曲数据始终存在于时间轴，观看窗口仅决定比例；轴、游标和点击使用同一歌曲时间映射，图形只受相机视锥和画布边界裁剪，平移后可查看窗口外数据。首尾时间桶覆盖歌曲边界。
- 显示网格最多 512 时间列（含末端点）×256 分量组；概览均匀聚合，局部可见时两侧各最多 64 粗桶，其余列细化可见区。缓存整曲聚合，保留绝对极值符号及切片 min/max；不减少可选原始分量。
- 镜头平移/旋转/加减、时间缩放和 resize 即时显示已有几何，稳定 150ms 后按真实投影补充网格；需要时通过当前 Analyzer lease 和共享窗口调度请求 Worker 原生分析帧，Wallpaper 保持 30Hz。旧请求与旧网格可取消，原始 compact payload、精确游标及缓存格式不变。
- 图表随置顶区及标题实际高度调整；单图表持有一个 WebGL renderer，静止时按需绘制，游标复用几何。切换/收起/离页释放 GPU、Observer、监听、捕获及任务；上下文丢失显示错误并可重试，不切换成其他 renderer。

## 区间与保存

- DEC-116：14 项 scalar 与 buffer 共用 Editor 顶部波形的绿色竖向包络、0.9 透明度及 6px 上下留白，Analyzer 使用无圆角/边框的渐变绘图区；多分量图保留原样。非负标量中线对称，有符号标量保持零线上下方向；固定范围沿用注册值，其他按可见绝对峰值归一化。像素合桶保留峰值，buffer 保留真实 min/max，游标层只画播放线，精确值仍由详情展示。Editor 叠加层共用画法及真实时间单元，不复制一套样式。

- 删除共享视口工具栏、pan/zoom/reset、手动排序及恢复默认排序入口。
- 上条约束保持 2D 共享时间工具栏不恢复；3D 的相机加减、投影视图按钮及局部平移/旋转见上一节。
- 仅图表绘图区内纵向滚轮缩放，以鼠标x对应时间为锚点，上滚1.12倍、下滚反向，范围1–64；边界处不滚动外层。
- Ctrl/Meta保留浏览器行为，图表之外正常滚动；所有图表完整同步start/end/zoom，点击和键盘定位播放继续保留。
- 高频wheel即时更新图表，持久化按RAF合并最新区间；换歌取消旧待保存区间，离页保存当前有效区间。既有revision/generation/cache隔离不变。
- V1 会话 carrier 保留，Analyzer 使用 `analyzerWorkspaceVersion:2`。移除旧排序字段和校验；旧工作区清空活动项、视口与分析缓存并写回，歌曲队列、句柄及独立草稿保留。列表只按 FEATURE_IDS 排列。
- 高度/说明不新增持久化字段，队列与区间继续恢复；Canvas renderer、音频时间基准、Editor/Visualizer接口不变。Observer、RAF、监听和指针捕获按所属组件释放。
