# Editor 工作区框架

owner 于 2026-10-16 要求实施“Editor 页面框架与控件改版”计划，并按三阶段验证后分别本地提交。本次统一公共框架，不改变标记、波形/BPM、分离、自动标记和叠加图表内部算法；工程仍为 JSON V1，不扩大正式 readiness 或发布授权。

2026-10-18 的内部标记重设计沿用此框架；波形独立视口、节拍／BPM、固定播放线、暂停编辑与轨道管理见[标记工作区](editor-marking.md)。该新契约替代下文历史交付记录中的共享时间列和 44px 轨道。

当前工程已按 2026-10-21 osu 导入计划升级 [V2](../architecture/editor/project-format-v2.md)，下文旧验证记录仍对应其历史实现。

## 顶栏与播放

- 统一深色平面顶栏：桌面 64px，细底线。左侧导入／导出使用 34px 点击区和 20px 线性 SVG；导入先打开类型选择弹窗，工程文件继续 JSON 流程，osu 谱面打开既有配置窗口。空状态保留 osu，工程文件提示先选择歌曲。选择类型前不访问文件；取消回到工作区。类型弹窗打开时暂停键盘标记录入，交接到后续导入结束后释放。
- 中部为标记编辑、音轨分离、自动标记页签；后两项显示 `exp`，无障碍名称注明实验性。支持方向键、Home、End 与 roving tabindex。可用内容宽度小于 800px 时移到第二行。窄屏两侧为导航和 Settings 留位。
- 右侧依次为新工程／保存中／已保存／未保存、叠加层开关和特征选择，最右侧沿用共享 Settings。完整工程错误保留在顶栏下方提示区。
- MusicBar 常驻，统一管理歌曲信息、播放、seek、音量与队列；Editor 不再重复歌曲名、艺人、播放时间或通用播放按钮。工作区租约继续强制单曲循环、锁定模式切换，离页恢复用户偏好。
- 波形右上为查看播放位置／添加分段的 30px 图标；缩放使用滚轮／快捷键，菜单重置全曲。新增轨道使用菜单，区间操作保留显式模式文字。

## 叠加层与草稿保护

`EditorAnalysisOverlay` 继续拥有开关、菜单和图表，控制区 Teleport 到 body、固定对齐顶栏右侧预留位，仅在标记编辑可用。菜单向下且右对齐，首次未选特征时开关打开原有菜单；焦点返回、三手柄、窗口级图表与指针穿透行为保持原合同。顶栏层级低于共享导航与 Settings，叠加层控件保持原独立层级。

换歌与队列保护见[应用外壳契约](app-shell.md#播放模式)。导航编排在 `useEditorTrackNavigation`；一次性目标／工程修订批准在 `EditorTrackChangeApproval`；控制器仍是工程保存与入口冲突检查的事实源。现有控制器和大编辑组件保留领域职责，本次只提取新增的顶栏、图标和导航编排，不按规模提示批量重构内部编辑逻辑。

## 实验工作区

音轨分离、自动标记在本次 Editor 页面会话中首次进入时分别显示 `EditorExperimentNotice`，复用草稿提示卡片样式，说明模型下载、本地处理及结果需复核；确认后显示内容，取消返回标记编辑并恢复页签焦点。确认仅保存在页面内存，重新进入 Editor 或刷新后再次提示，不写工程或偏好。工作区仍常驻，确认与切换不自动开始或取消任务。

自动标记使用同一深色卡片、薄荷绿主操作和通用数值控件，区分分析输入、任务进度、候选复核与缓存；候选筛选、修正、分页、试听、显式添加为新轨及清理确认保持原行为。窄屏只在候选表内横向滚动。

本轮通过类型检查、14 项分离／自动标记服务测试和 Chrome／Edge 共 12 项入口与布局回归；另外使用候选夹具核对复核表、筛选、长短分界、删除／恢复及进度／错误展示，检查 390/1024/1280/1920px 截图。未重跑模型推断或识别质量验收。

## 中央滚动框架

- Editor 使用 `calc(100dvh - var(--app-player-inset, 80px))`，不在 document 上滚动。MusicBar 的实测占高继续由其 ResizeObserver 发布，三种样式及切换动画均按实际 top 留位。
- 顶栏始终可见，切页签只使用 `v-show` 与现有 active 状态，不重启分离或自动标记。分离／自动标记继续各自 `.editor-panel.app-scrollbar` 滚动；标记页保持节拍区可见，`.marker-scroll.app-scrollbar` 独立滚动并保留 scrollTop。
- 所有滚动区域按实际溢出显示：共享 `.app-scrollbar` 使用 `scrollbar-gutter: auto`，无溢出时不保留背景空槽；内容增减、轨道折叠、窗口缩放及页签切换后由浏览器重新判定，不新增 JS 滚动状态或尺寸补偿。
- 顶栏保持原位，标记编辑内容区无外层 padding；分离和自动标记为 16px，视口宽度不超过 600px 时为 12px。留白包含在原有 MusicBar 占位内，不增加 document 滚动。波形仍为 88/72px，280px 左侧节拍栏、可折叠 BPM 区；轨道采用 224/160px 合并管理栏、36px 组标题和 48px 分类行。波形与轨道横向滚动及时间视图分别独立。
- 空、加载、不可用和损坏状态使用原有状态外框及可滚动状态区；草稿冲突使用居中卡片，参照 Visualizer 的图标、文件名和独立底部操作区，保留导出、明确覆盖、取消及导出结果提示。
- 离页提示由 `EditorLeaveGuard` 处理原生 dialog 与路由 guard，沿用草稿卡片样式，默认聚焦“留在此页”；关闭、Escape、背景取消和“不再提示”的保存规则不变。刷新继续由 controller 的 beforeunload 保护；未增加持久化字段。

## 本次验证

第一阶段：类型检查、35 项播放／会话／处理生命周期测试及 Chrome 两项换歌保护回归通过，覆盖保存失败、取消、明确覆盖、导出、刷新、当前项删除和清空。

第二阶段：Chrome 三项框架回归及七项叠加层集成测试通过，覆盖页签键盘、菜单方向、首次选择、焦点和三个手柄入口。

第三阶段在 Windows 的 Chrome / Edge 151.0.7922.34 上分批执行并收口：

- 类型检查和 25 文件、132 项 Editor／播放恢复／分离及自动标记服务测试通过。
- 双浏览器共 118 个不同测试实例通过：E1–E5、E7–E10、editor-frame、editor-navigation-lifecycle、editor-ft。包含 1024/1280/1920px、390px 入口、侧栏两种状态、三种播放器样式及动画、内部滚动恢复、错误提示、草稿与队列保护、播放拖动／键盘 seek、音量及离页模式恢复。
- 其中 16 项 FT 检查使用已有本地四模型，验证真实分离、WAV 字节与校验、缓存往返、MusicBar 暂停／恢复 FT 试听、取消／重试及失败隔离。
- 波形 88/72px、轨道 44px、名称列 152px、分类列 144px 保持原值，时间层、波形与叠加层对齐误差不超过 1 CSS px；检查桌面与窄屏截图。
- 首轮 BPM 摘要断言使用旧可用宽度，调整测试输入后三级展示与原几何门槛复测通过。额外点／范围回归发现右键平移把深度响应式指针中的 viewport 代理带入工程，触发 `structuredClone`；将两个瞬时指针改为 shallowRef 后 28 项原专项通过，未改变平移、吸附或标记算法。
- 已同步技能入口、地图和当前契约，并运行 repo、文档链接与 diff 检查。工具实现、依赖、打包和媒体格式没有变更，未运行应用构建或正式 canonical/readiness；历史许可与证据缺口保留。

这批结果为当前工作树功能回归，不改变历史 canonical 身份或发布状态。E6 的长曲／10,000 事件性能与完整自动标记模型质量门禁没有在本轮重跑；现有相关测试仅更新公共控件选择器。
