# Visualizer 几何元素与预设

owner 于 2026-10-16 要求：新增可独立编辑的原子视觉元素，复刻 Wallpaper Engine workshop 3093808768 的 geometric visualizer（responsiveness 0.6），在元素库增加“预设”，并额外创作歌曲 PV 风格组合；每个完成阶段单独本地提交。

本任务扩展现有 Project V3 ElementRegistry 与组合器，不注册完整内置 Scene，不引入新的 Canvas、renderer 或 RAF。预设最终展开为普通元素，可单独修改及删除，导出与草稿沿用现有 V3 codec；后续修正中 owner 补充授权 [原生 Web Audio 输入](visualizer-native-input.md) 及对应 source 类型。

2026-10-17 当前修订：[Wallpaper Engine 风格频谱（近似）](wallpaper-spectrum.md)成为新版“几何律动”的默认输入，完整 128 向量直接乘 0.6。原生输入恢复线性 FFT byte bin 与有符号波形；撤回特殊分频、空间平滑、平方响应、2/3 校准和环向零尾/接缝适配。原工程不改绑，原几何棱锥、旋转中心与半径修正保留。下方原生适配及零尾修正段落为历史记录，其当前行为由本段和链接合同替代。

## 原项目与响应

参考为 owner 指定的本地 index.html、project.json 和两张静音/播放截图；不复制其 p5 运行库、字体或远程依赖。源实现为双环频谱、12 个频段方块、中心方块/棱锥、三个旋转环、三个小棱锥和 19 条弧。截图未显示曲名；复刻按该视觉组合执行。

原项目的输入为 Wallpaper Engine 音频数组，[官方音频文档](https://docs.wallpaperengine.io/en/web/audio/visualizer.html)定义左右各 64 个频段。当前默认使用独立近似提取器的立体声 128 向量，允许短时超过 1，直接乘 0.6，不再次使用 Meyda 幅度标度。既有 Amplitude Spectrum 绑定仍将 mono 64 段复制到左右槽位；原生输入在渲染层进行固定单位换算。双环按完整数组直接重复，包括真实零尾和声道接缝。双环、尺寸、弧线和填色公式沿源结构。源逐帧旋转以 60 fps 转为绝对歌曲秒；随机彩色改用 seed 和绝对帧索引，seek/循环/录制可重现。

几何以短边 1600 为设计参考，位置为归一化画面坐标。新增环形频谱、轨道几何体、旋转线框和旋转弧簇；形状、数量、半径、尺寸、速度、相位、阈值、线宽与响应系数可独立编辑。线段使用三角形，避免依赖平台 WebGL 宽线支持。几何仅共用一组动态 BufferGeometry/ShaderMaterial，并在组合器释放时回收。

## owner 反馈后的修正

本轮对照了原作使用的 p5 1.8 源码：`cone(...,4)` 包含接缝顶点，实际为三角底面，初版误作四角底面且顶底方向相反；中心棱锥应在 Y/X/Z 旋转之后作局部 20px 平移，小棱锥高宽比为 16/12 且不带外围方块的逐个自转相位。现已修正这些几何，以及 p5 矩阵右乘的旋转顺序和屏幕 Y 方向。中心位移随自转一起变换，投影中心不再固定在旧模型的中心。

内外环继续使用源半径公式：外环基础半径乘 `(1+peak)*(1+band)`，内环基础半径乘 `(1+band)`；原生输入的固定标度修正负责避免上游饱和把整个环过度放大，响应系数仍为 0.6。既有草稿不自动改绑，重新添加预设或手动切换为“原生输入 → 频谱（立体声）”即可使用新链路。环向 band 排列在下方零尾修正中另作展示适配，不再声称沿用原作的数组直接重复。

本轮类型检查及 62 项 Visualizer 测试通过；Chrome/Edge 完整 Visualizer 回归 46/46 通过，补齐标准混音与弦线原生历史后相关 10/10 再次通过。包含原生来源/可用特征切换、真实左右异频/单声道/多声道 FFT、API 失败重试、草稿恢复、实际音频和 WebM；已检查本地音乐两个时段修改前后的全屏画面。验证边界仍为本地功能回归，不改写历史 readiness。

## 连续零尾与环向接缝修正

owner 再次反馈 Analyzer 与原生输入均仍存在尾端平直圆弧和陡直峰值。逐行核对原 `wallpaperAudioListener`：仅乘 responsiveness、复制数组、使用 `0.1+0.1*band` 基础半径并 closePath；`subArray = x-0.5` 未被绘图使用，没有额外去零、镜像或平滑。直接执行原回调，左右各 64 band、尾部各 24 个零、responsiveness 0.6 的受控输入同样得到接缝跳变（1600×1600 时外环接缝半径 640→1024）。原作画面差别不能据此归因于一段漏抄的去零代码；WE 上游频谱与本地输入仍不等价。

owner 随后澄清：原作也有真实零值，只是通常没有长零尾，不应激进去除静音。本次因此保留低→高的原频率顺序，不镜像、不全面平滑：仅当每声道低于自身峰值 0.1% 的连续尾段超过 8 band，才缩短显示范围，并仍保留 4 个尾部 band；未超长的输入逐点原样使用。只有被缩短的接缝在两侧各作至多两个采样点的轻微过渡。内部波谷、短零尾和整段静音保留；不添加最低能量、不修改原始分析数组，也不改变其他几何的 peak、阈值或响应系数。此项是本地环形展示修正，不是对原文件处理步骤的逐字复刻；既有工程重绘即生效，无需重建预设。

专项覆盖 Analyzer/原生立体声的长零尾、近零尾、1/4/8 band 短零尾逐点不变、频率顺序、静音、恒定输入、内部静默区、两种重复次数的闭合与确定性。真实浏览器的受控输入包含长零尾，额外本地音乐检查同时切换原生与 Analyzer，防止只验证其中一路。

最终类型检查与 68 项 Visualizer 测试通过；Chrome/Edge 针对性回归 4/4 通过，包含长零尾受控频谱和本地音乐两处时段的原生/Analyzer 全屏画面检查。短静默和部分接缝起伏仍可出现，这是保留真实输入的预期行为。此次局部展示修正不改变既有 readiness 边界。
