## 点标记直线测试（DEC-090）

`point-line-horizontal`（点标记横线）贯穿画面宽度、随机高度；`point-line-vertical`（点标记竖线）贯穿画面高度、随机横向位置。两个元素及算法内容版本为 1，使用 ABI 2。用户已明确批准两份具体合同；记录随外部 source/content-contract.md 保存。

输入只允许点轨道中的一个分类，换轨道解除分类绑定，不自动选择；空分类透明，未绑定阻止导出。每点独立触发且可叠加，中心在对应方向的 1%–99% 内，时间相邻两点位置差至少为画面对应尺寸的 5%。seed、方向、事件 ID 和时间顺序决定位置，seek、循环与离线帧一致。

默认白色，线宽为短边 0.003（可调 0.0005–0.02）；点前 0.04 秒平滑渐显、点时刻最亮、停留 0.06 秒、再用 0.10 秒平滑渐隐。渐显/渐隐可调 0.01–0.5 秒，停留可调 0–1 秒。仅触发手动时段内的点，边界裁剪；includeEnd 使曲尾点能提前渐显，不延长导出。

每修订分页缓存单分类事件及位置，每帧二分活动窗口；按既有顶点容量分批，后续批次先复制前一批结果，不截断密集事件。资源自带完整源码、Shader、独立 SVG 和运行包；不更改原有 15 个资源。

## 几何律动

- 预设包含11个可独立编辑元素；黑背景不请求分析。数量为12的方块形“轨道几何体”默认amplitudeSpectrum full，其余频谱输入默认wallpaperEngineSpectrum full，新建共请求两项，响应系数0.6；导入/旧草稿不自动改绑。共同控件“十二频段方块输入”保留其用途标签，目标仍仅此实例。
- Wallpaper近似输入为左右各64的立体声128向量，允许短时>1，直接乘0.6，不再次按Meyda标度换算。双环直接使用完整数组，保留真实零尾和声道接缝。
- 已有Amplitude Spectrum绑定把mono64段复制到左右槽；native采用[当前线性FFT byte bins/有符号波形](visualizer-native-input.md)及固定单位换算。旧特殊分频、空间平滑、平方响应、2/3校准和环向零尾适配已删除。
- 几何以短边1600为设计参考、位置归一化；形状/数量/半径/尺寸/速度/相位/阈值/线宽/响应可编辑。线段用三角形，共享动态BufferGeometry/ShaderMaterial并对称释放。
- 源逐帧旋转以60fps转为绝对歌曲秒，随机颜色采用seed/绝对帧索引；seek、循环与离线输出可重现，不引入独立Scene/Canvas/renderer/RAF。

## 棱镜航行

12个元素包含可独立添加的光轨隧道和跃迁星尘。四段默认分镜覆盖0–18%、18–46%、46–80%、80–100%，对应六边、方形、三角、八边隧道；只是可修改默认时段，不声称识别副歌或节拍。隧道采用深度投影、双色光晕和绝对时间扭转，星尘轨道由seed固定。

## 分组与共同处理参数

预设库按[实时样式](visualizer-realtime.md)提供用途筛选，能力由当前有效元素、绑定、算法合同和时段计算。当前默认“几何律动”可实时应用，但幅度谱绑定使其不满足壁纸导出；“棱镜航行”的局部分镜归为歌曲专用。修改绑定/时段后对实际工程重新判断，不自动改写预设默认值。

V6继续把预设保留为默认折叠顶层组，移动整组、组内排序、显隐/删除与effect目标清理按工程契约。共同处理控件仅在声明范围内批量写入；单独修改子元素显示差异，再次应用共同值覆盖目标字段。几何律动两种输入分别声明控件，棱镜航行保留其输入/分镜，不把样式常量混作共同处理参数。

## 用户预设导出（DEC-100）

目标为资源商城当前已加载的资源文件夹。点击保存才申请写权限，先验证元素精确依赖；缺少元素或版本/hash 不一致时列出明细并停止，不补齐或覆盖 elements。仅创建 presets/user-preset-<UUID>/，版本为 1，包含 resource-info.json、source/resource.json、resource-package.json 和封面。信息文件最后写入；取消/失败清理本次目录，清理失败报告路径。刷新商城后展示自定义元数据并可重复添加，既有预设仍按原规则加载。

V2 可选 Seed 和媒体字段见[资源包](../architecture/visualizer/resource-packages-v2.md)。导出前使用现有实时候选隔离验证；关闭弹窗、配置变化、换歌或离页取消旧任务并释放封面 URL。运行时资源不写入工程或 store。
