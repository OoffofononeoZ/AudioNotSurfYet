## 2026-10-19 数字键实时录入

owner 批准 DEC-085 的执行计划：按轨道顺序展开分类行，前十行对应 `1–9、0`（主键盘与 NumLock 小键盘）。折叠不改变编号；播放时点标记按下即创建，范围按下记录起点、松开结束，可同时录入多行。端点读取共享 engine 即时快照并跟随当前节拍细分；正常短按补到下一格，暂停／曲终按停止位置收尾且不足一格不创建。跳转、换源／换歌、切页签、工程／网格变化、失焦／隐藏、输入控件／弹窗与离页取消未完成录入。

`KeyboardMarkerRecorder` 持有纯运行时按键／范围状态，composable 管理监听与 preview；Editor 提供 controller 最新工程，逐项校验后合并写回，草稿沿用防抖。鼠标及管理仍须暂停，原鼠标两次点击范围状态独立。未改工程格式、音频所有权或正式 readiness；完整规则见[交互契约](../architecture/editor/interaction-contracts.md#数字键实时录入dec-085)。数字录入是播放中允许的特定路径，鼠标和管理继续要求暂停。

本轮功能验证：8 文件、51 项录入／播放／点范围持久化单元与集成通过，类型和显式文件格式检查通过；Chrome／Edge 各 12 项新录入及相邻标记回归通过，覆盖多键、正常／停止端点、曲终循环、取消、同 ID 工程导入、输入保护和各三次离页重进的监听释放。1280／390px 截图已目视复核，保存在忽略目录 `artifacts/editor-marking/keyboard-recording-*.png`。技能入口、代码地图、仓库及文档链接检查通过；未改变依赖、打包或媒体算法，不运行应用构建和模型推断。


## 当前页面与编辑

- 波形/tempo默认全曲并保存工程viewport，marker/overlay独立MarkerTimeView，1–10秒跨度、默认10秒，播放线固定15%，歌曲边界外留白。播放帧不改工程/草稿，BPM不重置视图。
- 上方节拍区保持可见；下方轨道列表独立滚动。管理栏224/160px、组标题36px、分类行48px、会话折叠；分类迁移/明确删除、非空轨确认和最后一轨删除保留。
- 普通滚轮只在轨道时间绘图区缩放，Ctrl/Meta保留浏览器；拖动冻结缩放，seek/播放/换源取消临时态。暂停鼠标/菜单/批量不修改播放线左侧，数字录入按自己的吸附规则处理。
- point是居中短键、range同高长条；两次点击的范围起点可跨同歌导航保留。单项/小节批量预校验后一次提交，重复/重叠/越界拒绝，Esc/失焦/捕获丢失清理临时态。具体键盘、吸附和范围包含规则只维护在交互契约。
- 常规/三连音/自定义1–64细分共用，默认每拍四等分，zoom只影响次级线密度。手动定时默认收起；bpm测算仅按真实点按间隔，从第二次起持续平均，最多128间隔、4秒无输入重置。播放、倍速和当前区间选择不影响测算，显式应用才修改当前区间。
- overlay复用Canvas adapter、独立轨道视图和标尺几何，fixed/pointer-through与焦点/菜单按当前契约。JSON V1、事件秒数及分离/自动标记所有权不由页面重排改变。
