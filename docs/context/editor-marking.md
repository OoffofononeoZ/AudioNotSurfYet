## 2026-10-26 整轨移动（DEC-102）

“标记补偿”后提供“轨道操作”，沿用暂停可编辑条件；无标记时禁用。弹窗默认选择首个非空轨道，正整数格数默认 1、步长 1，可前移或后移；覆盖所选轨道所有分类与全部标记，包含折叠和视野外事件。点或范围两端先吸附到当前网格，再按严格相邻刻度移动；跨 BPM 不保证原秒数间隔或范围长度，single-beat 整段计一格。格数采用安全整数，不设业务上限，不枚举整曲网格。

`moveMarkerLane` 一次计算、校验完整候选，任一越界、无可用网格、同分类点重复、范围不足一格或重叠即拒绝整轨；成功保留事件 ID、分类和名称，其他轨道不变，只更新/保存一次。打开弹窗清除拖动、待完成范围及区间选区；工程、细分、播放或工作区变化关闭弹窗并丢弃旧操作。该操作不新增撤销历史，不改变工程格式。

## 2026-10-19 数字键实时录入

owner 批准 DEC-085 的执行计划：按轨道顺序展开分类行，前十行对应 `1–9、0`（主键盘与 NumLock 小键盘）。折叠不改变编号；播放时点标记按下即创建，范围按下记录起点、松开结束，可同时录入多行。端点读取共享 engine 即时快照并跟随当前节拍细分；正常短按补到下一格，暂停／曲终按停止位置收尾且不足一格不创建。跳转、换源／换歌、切页签、工程／网格变化、失焦／隐藏、输入控件／弹窗与离页取消未完成录入。

`KeyboardMarkerRecorder` 持有纯运行时按键／范围状态，composable 管理监听与 preview；Editor 提供 controller 最新工程，逐项校验后合并写回，草稿沿用防抖。鼠标标记编辑及管理仍须暂停，原鼠标两次点击范围状态独立。未改工程格式、音频所有权或正式 readiness；完整规则见[交互契约](../architecture/editor/interaction-contracts.md#数字键实时录入dec-085)。播放时可数字录入和拖动时间行，标记的鼠标编辑与管理继续要求暂停。

## 当前页面与编辑

- 波形/tempo默认全曲并保存工程viewport，marker/overlay独立MarkerTimeView，1–10秒跨度、默认10秒，播放线固定15%，歌曲边界外留白。播放帧不改工程/草稿，BPM不重置视图。
- 上方节拍区保持可见；下方轨道列表独立滚动。管理栏224/160px、组标题36px、分类行48px、会话折叠；分类迁移/明确删除、非空轨确认和最后一轨删除保留。
- 普通滚轮只在轨道时间绘图区缩放，Ctrl/Meta保留浏览器；拖动冻结缩放，seek/播放/换源取消临时态。暂停后鼠标/键盘/菜单/批量可操作整条可见轨道的有效歌曲时间。15%播放线及左侧遮罩外观保留，遮罩不限制操作；播放仍用数字录入。
- 顶部时间行支持左键拖动刻度带，左拖前进、右拖后退，连续微调共享播放时间并保留播放状态；BPM分段新增与位置调整也连续定位，标记吸附保持当前细分。区间模式右键拖动显示浅红色删除预览，松开一次删除，取消保留原选区。Editor普通文字禁止选择，输入控件保留选字能力，离页恢复其他页面。
- point是居中短键、range同高长条；两次点击的范围起点可跨同歌导航保留。单项/连续时间批量预校验后一次提交，重复/重叠/越界拒绝，Esc/失焦/捕获丢失清理临时态。具体键盘、吸附和范围包含规则只维护在交互契约。
- 常规/三连音/自定义1–64细分共用，默认每拍四等分，zoom只影响次级线密度。手动定时默认收起；bpm测算仅按真实点按间隔，从第二次起持续平均，最多128间隔、4秒无输入重置。播放、倍速和当前区间选择不影响测算，显式应用才修改当前区间。
- overlay复用Canvas adapter、独立轨道视图和标尺几何，fixed/pointer-through与焦点/菜单按当前契约。JSON V2、事件秒数及分离/自动标记所有权不由页面重排改变。

## 图表细节与时间对齐（DEC-094）

叠加图按真实样本时间绘制，与轨道共用 15% 播放线和曲首／曲尾留白，不拉伸剩余数据。顶部波形保持独立视窗；两处 Buffer 图均在概览精度不足时，从既有 Worker 的 mono PCM 按显示像素求 min/max，时间桶按二次幂细化，最低一个原始采样点。

普通叠加特征补算窗口内未聚合的 1024 frame／512 hop，保持原算法；48kHz 下步长约 10.67ms，Wallpaper 频谱维持原生 30Hz。频谱行数随图层高度／DPR 调整；时间或频率需要合并时保留峰值，复频谱相位取同一峰值位置，分类维度不合并。

播放及暂停均自动更新。连续缩放时现有数据跟随视窗，停止 150ms 后才补算；顶部与叠加层独立管理当前窗口及前后各一窗的缓存，接近边缘时预取。每视图最多一个运行请求和最新待处理视窗；换歌、换特征、关闭及离页取消旧请求，迟到结果按身份拒绝。窗口结果仅属运行时，不进入 Pinia、工程或持久化分析缓存；等待或补算失败时继续绘制坐标正确的概览。
