# Editor 标记编辑改版

2026-10-17 owner 批准参考“样式修改editor和visualizer”对话及 osu 编辑代码改版，仅修改标记编辑。横向多轨、点轨／范围轨新增、JSON V1、原始秒数和草稿边界不变；不修改音轨分离或自动标记的界面、推断及应用逻辑。

## 交付约定

本任务按五阶段分别验证并本地提交，再进入下一阶段；这取代本任务默认的一次提交交付，不推送、不重写历史。阶段为：样式／菜单／轨道删除、细分和彩色网格、手动定时、局部窗口与单项移动、整体回归与文档。未实现部分不视为通过。

## 当前实现

- 时间轴、点轨和范围轨通过同一 body 级浮动菜单提供定位、播放和居中；实测尺寸后在视口内定位，空间不足时自身滚动。菜单支持键盘与焦点返回，外部点击、滚动、resize 或卸载清理；同一时刻只有一个。
- 保留已有标记右键删除、范围 pending 取消和右键平移的优先级。菜单不再被 44px 轨道或波形容器裁剪。
- 每条轨道有常驻删除按钮；空轨直接删除，非空轨用原生深色 dialog 明确确认轨道及事件数量。可以删除最后一条轨道；删除清理该组件交互并将焦点移至相邻轨道或新增按钮。
- 标记工作区复用平面主题、紧凑标题和图标，分离与自动标记样式保持原状。

## 节拍与局部编辑

细分与彩色网格已实现：常规 1/2/4/8/16、三连音 1/3/6/12、自定义 1–64 的因数预设；初始每拍四等分，预设切换与颜色层级沿用 osu。每拍细分数决定所有入口的吸附，缩放只影响次级线显示。自定义最大值与当前选择分别持久化在按歌曲 hash 隔离的 preferences 中，JSON V1 不增加字段。tempo 和点候选共同约束到当前区间结束，已有事件秒数不变。

手动定时已实现：默认收起，展开后左侧为 tempo 区间列表，右侧为约 350px BPM 辅助栏；窄屏改为上下布局。区间选择、原时间条和内部边界联动；辅助栏使用共享 AppSelect/AppNumberInput 编辑起点、BPM 和拍号。起点毫秒显示但不量化原有秒数；首段固定，越过相邻边界的输入拒绝。节拍相位来自现有 playback snapshot，不增加时钟或音频资源。

Tap 沿用 osu 的前四次热身、八次起预览与最多 128 个有效样本策略，4 秒无输入重置以覆盖 20 BPM；只在用户点击应用时更改当前区间，支持单拍区间显式恢复 metered。收起、选择变化、切页签、换歌或离页释放点按状态及 timer。

局部视口与单项移动已实现：默认四小节，重置回四小节，提供 1/2/4/8 小节、全曲及查看播放位置。最小窗口为相关 tempo 区间的一小节；歌曲更短则显示全曲；无有效 BPM 默认十秒、最小一秒。初次进入将全曲视口转为四小节，已保存局部视口恢复；尚未手动调整视口时，BPM 就绪／修改同步默认小节窗口。Editor 使用独立窗口限制，Analyzer 的 1–64 缩放不变，工程继续使用原 viewport 字段。

短音为居中实心短键、范围为同高长条。单项拖动和 Alt+左右仅在同轨／同分类内移动，范围整体保留长度；预览期间不写工程，松开后再次核验源事件、tempo、viewport 与细分身份再原子提交，冲突、Esc、捕获丢失、失焦、切页签和离页清理。端点编辑、小节批量及 Ctrl+C 向后复制保持原逻辑。撤销／重做、跨轨多选、完整剪贴板、自由时间及音色分组留待后续。

窄屏保留共享列宽，时间轴与所有轨道的物理横向滚动同步；节拍工具栏、轨道工具栏和手动定时区固定在滚动容器左缘。新增滚动区复用 `.app-scrollbar`，同步监听在 Editor 卸载时释放。
