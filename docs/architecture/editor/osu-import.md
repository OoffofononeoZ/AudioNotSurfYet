# osu 谱面导入

核查日期：2026-10-21。DEC-093 授权 Editor 的单向谱面转换；工程输出为 [V2](project-format-v2.md)，不提供 osu 导出。解析与转换位于 `src/editor/osu/`。

## 支持与映射

- 首轮读取 UTF-8 v14，支持标准（0）、太鼓（1）及 mania（3）；其他版本、catch（2）给出明确诊断，不猜测兼容。
- `.osu` 提供一个难度；`.osz` 使用锁定的 fflate 0.8.3 异步读取 ZIP，只解析 `.osu`，选定后按引用读取目标音频。单个难度解析错误独立显示；背景、视频、音效不解压。
- Circle／短按为点，Slider／Spinner／Hold 为范围；轨道按类型创建并包含难度名，mania 按键位分类。仅保存时间和分类，不推断乐器、复现游戏轨迹或播放击打音。
- 物件类型按 bit flags 读取；滑条按正长度、行程数、SliderMultiplier 和起点定时计算端点。标准模式沿用 osu 的 SV 浮点精度规则。隐式零长度曲线和非法端点明确拒绝，不静默生成短音或截断范围。
- 书签为可选点轨道，休息及 Kiai 为可选范围轨道；Kiai 按状态形成连续区间，歌曲外的状态只用于确定歌曲内区间。所有选定标记经 V2 严格边界、重复及同类重叠检查。

## 定时与应用

- 红线提供 BPM、每小节拍数和锚点，拍号表示为 n/4；绿线控制 SV／Kiai，不生成 BPM 分段。同刻采用首个红线及最后一个绿线的有效控制值。
- 第一段从 0 开始，使用 0 秒有效红线或首个未来红线的锚点，保留后续真实红线。同 BPM 重新定相不合并；导入范围 10–1200 BPM，不倍频、截断或重新吸附音符。
- `applyOsuBeatmap` 只构造完整候选，不修改输入工程；默认追加新轨道，重复导入产生独立批次。tempo 独立选择替换，已有设置默认保留；空 tempo 默认填入。
- 整批校验失败不返回部分结果。源音频的实际解码时长决定边界，不能仅用谱面的最后一个物件冒充歌曲长度。

## 验证

合成用例覆盖时长、重复滑条、红绿线优先级、同 BPM 定相、mania 和弦／长按、附加轨道、冲突、取消与 ZIP 错误。`tests/editor/osu-reference.test.ts` 只在提供 `OSU_REFERENCE_ROOT` 时读取外部样本，谱面和音频不进入仓库；当前参考集为 18 个难度、9,392 个物件、3 个压缩包。参考数据通过不代表其他模式或版本受支持。
