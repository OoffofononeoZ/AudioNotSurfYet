## 范围与模型

| 输入与能力 | 固定路线 | 边界 |
| --- | --- | --- |
| 当前 FT drums → 完整鼓候选 | ADT_STR ONNX encoder / decoder，默认 Worker WebGPU，显式慢速 WASM | 批 8／尾批实际大小、完整前缀贪心、上限 512；自定义词表映射 kick/snare/hat/tom/crash/ride/clap/percussion/unknown，不同 customPitch 保留独立声音身份。 |
| 当前 FT bass、vocals、other → 音符 | 官方 Basic Pitch ONNX，Worker WASM | 保留音高与音符实际起止；other 另生成主旋律角色候选，不估计混响或 release 拖尾。 |
| 原曲 PCM → 钢琴、吉他候选 → 音符 | 独立 htdemucs_6s 辅助分析，再逐乐器 Basic Pitch | 只保留钢琴／吉他输出；乐器身份是待复核候选，和 FT other 的疑似串音进入跨来源复核。 |

FX、Pad 和合成器预设身份区分，以及 YourMT3+ 转换／部署留待后续。处理共享于 Web/Electron 的 renderer 和专用 Worker，不要求 Python、本地服务或外部辅助程序。已有四轨 FT 继续使用原固定模型与 WebGPU 配置，六轨辅助结果不能替代四轨试听。

模型、ORT 部署资产、算法配置、输入／输出 tensor、采样率、频谱、分段、词表与时间偏移共同进入可验证的固定身份。生产 URL 使用 immutable revision；下载校验失败明确报错，不增加静默模型或 provider fallback。ADT_STR 权重及改编按已接受的独立 CC BY-SA 4.0 边界保存上游、转换来源、归因与改编信息；应用代码不因模型卡而被宣称已获任何额外许可。

鼓转录使用独立 session 配置：校验下载字节后仅在 WebGPU 内存中展开常量反量化，图优化 `all`，编码中间量驻留 GPU；不改 FT/辅助 session。辅助分析先完成并释放，鼓链复用同一 ORT 模块已初始化的 GPU adapter，避免重复赋值只读属性。仅鼓任务仍可独立初始化。完整前缀保留原模型注意力语义，不加入常规 KV cache。

鼓输入 2.56 秒、25% 上下文重叠，每窗负责中央 1.92 秒；首尾补零、按绝对秒裁切。达到上限或连续四次相同完整事件且时间不前进时，该负责区间拆为两个有更多上下文的子窗，最多一轮；仍失败区间候选不应用，其余区域继续并显示 partial。每步/批次释放张量，进度按 250ms 限流并保留心跳和阶段终止消息。

设备保护只观察 ORT 实际使用的 GPUDevice，不请求另一个设备或 provider。实际设备丢失时结束可能悬挂的 session 创建/推断，尝试释放全部 session/tensor，由控制器结束 Worker；错误保留为 `webgpu-device-lost`。Electron 的已知 GPU map AbortError 可能先于丢失通知：仅对此精确类型/文案暂存最多 50ms，确认丢失则结束所属任务；未确认丢失或正常释放时用 `reportError` 报告原异常，其他错误不延迟。定时器随确认/释放清理，不把失败结果保存为完成，不自动改用 WASM。

内部结果/缓存 envelope 为 V2，包含鼓 backend/config hash、独立 analysisConfigHash、未完成区间和可选声学证据；EditorProjectV2 不变。旧内部缓存保留但不恢复，切换 backend/词表/音符或声学配置隔离结果；原辅助分离 configHash 及来源身份不改。主要音色与音符视图、灵敏度、组名/归属和重复选择由独立 ReviewSettings 保存到本机候选缓存，改变设置只重算派生预览，不改原始候选或重跑模型。

## 主要音色与复核

- FT other 用已有 Basic Pitch 参数生成原始音符，再以 20ms 帧、最多 12 个音符和独立静音状态求连续角色路径，结合模型激活、局部显著性、chroma 音高支持与换音代价。路径覆盖及相对判别余量足够才标为主旋律候选，含糊和弦保留 other；二者共享原始事件，不重复进入默认组。用户可改音乐角色并恢复自动判断，原始路径证据保留。角色不表示合成器/音色预设身份，证据值不是准确率。

2026-11-10 六输入完整链 Chrome/Edge（`chrome-1794292976410`、`edge-1794293131206`）及实际 ASAR `transcription-c3b2d3f5-c449-424d-909a-eb77ed11ad16` 通过原有推理/试听/应用/恢复/离线重算/取消/损坏保护；other 在短样例实际产出 20 条带路径证据候选，因相近证据保留 other。主旋律选择另有旋律/和声/静音专项，当前 78 项转录单元通过；此处只证明实现行为，不表示主旋律听感质量接受。

- 每条已完成音轨用已有 Meyda/MonoResampler 建立有界 DSP 索引（22050Hz、1024 帧、512 hop、每块 128 帧），保留候选的 RMS、局部显著性、谱变化起音、MFCC/chroma 和独立开启/关闭门限产生的活动区间。索引按 Worker 所有权释放，不驻留所有音轨 PCM；这些数值与模型激活、鼓 velocity 分开，均不是准确率。
- 音符原始解码按 bass/vocals/piano/guitar 配置门限、最短帧数、结束间隙和相邻音高抑制；首尾帧、短重复音、相邻和弦音高及跨窗连续时间独立验证。参数见 `analysisOptions.ts`，不改分离模型。

## 同曲示例检索

- 默认使用当前原曲，未分离也可检索；其他来源仅列出当前已有 FT 与已完成辅助音轨，不启动新分离。可将选中的点/范围标记或区间操作选区带入示例面板，也可用播放位置和秒数设置示例。多个正例和明确反例分别保存，未标声音不自动当作反例。
- Worker 复用有界 DSP 索引。点检索相似起音，范围先以 MFCC 粗筛，再用最多 192 帧、滚动两行的受限 DTW 比较声音/乐句；采用有限时长比例，不能视为任意节奏、配器变化的识别器。MFCC 零阶不承担匹配，避免仅按音量判断；相似度与反例差值不是准确率。
- 原曲通过当前解码 revision 的有界 PCM 副本读取；分轨在执行前校验现有结果与文件身份。索引无 PCM，按完整来源、DSP 配置及 typed array 校验和存本机 `editor-sound-examples`，与模型候选缓存独立。示例、声音组、门限、复核项及上次来源/组选择按歌曲恢复；来源尚未恢复时等待可用后核对，用户新选择优先。旧来源的示例不会套在另一轨上。
- 匹配项默认未勾选，支持来源试听、边界修正，再显式原子应用到 V2 标记轨。点采用稳定起音身份；同组已表示的范围和已存在的示例标记避免重复。应用过的事件即使手工移动边界，仍能按来源 ID 识别；重新查询不会删除或覆盖人工内容。
- 模型与示例任务共用处理槽；取消直接结束所属 Worker，换歌/解码变化校验 generation，旧结果不能发布。试听使用现有 transport，不创建额外 AudioContext。清理当前索引保留示例/工程；清理全部自动标记结果同时清理示例与索引，工程标记保留。存储失败保留当前编辑并提示未保存，可重试。

受控 CC0 变音量重复乐句及反序反例在 Chrome/Edge 完整示例流程通过，包含标记→示例、试听、边界修正、勾选/重复应用、刷新恢复、索引复用、取消及窄屏。六输入完整链 `chrome-1794296184646` / `edge-1794296365106` 另验证原曲、FT other、已有辅助钢琴三个实际来源及清理后的工程保护；ASAR `transcription-c583b633-caa3-4219-a718-626a2544e3a7` 独立通过三个来源、实际应用、离线恢复/重算及原有取消/损坏保护。同曲示例提交 `0f65c26`，当时 91 项单元通过。

## 试听 transport

- 四条真实 FT 音轨分别静音，默认全部未静音；统一播放／暂停播放所有未静音轨，提供返回原曲入口。鼓种只是标记类别，不新增鼓内音源分离或 kick/snare/hat 静音。
- 复用唯一 AudioEngine 的 AudioContext、播放时钟、暂停、seek、总音量、全局变速、结束和 Editor repeat-one 策略。原曲／FT／辅助乐器切换保留当前原曲绝对秒数和速度，音高随原生 playbackRate 变化。PlaybackSnapshot 明确提供速度、当前试听来源与等待／读取错误；变速前取消未提交标记，分块读取检查 generation 后按新速度重排。
- 初始 PCM 块约四秒、提前准备八秒；使用有界文件读取与节点调度，不整体解码或驻留四条长音轨。读取未就绪／失败必须停止有效播放时钟推进并显示状态，不能让游标继续前进而没有音频。
- 钢琴／吉他候选复用同一 transport 试听辅助音频。切回标记工作区保留试听；换歌、确认离开 Editor、清理相关缓存或 dispose 结束读取与试听租约，返回原曲并释放节点、buffer、监听及文件引用。

## 分析、候选与身份

- 分轨选择决定任务；phase、已完成单位、总单位与 elapsed 来自真实下载、预处理、推断、解码和写入。没有总单位的初始化阶段保持不定进度，不捏造整体百分比。
- 辅助六轨分析从原曲 PCM 开始，分段 overlap-add 后只将钢琴／吉他分块写入 OPFS；释放六轨 session／输出 tensor 后逐乐器转写，不能让所有模型和全曲音轨同时驻留内存。
- 原始候选保留稳定 ID、原曲起止秒数、音高或 customPitch、乐器候选、模型激活/velocity、声学证据及完整来源身份。默认逐轨 300ms 分界，调整只重算点/范围；音符细节保持实际结束时间。
- drums 输出 point；同刻不同自定义声音可以并存。音符细节 range 为单音持续时间，主要音色 range 为合并后的实际活动，均不是小节或按 BPM 吸附的段落。
- 删除/恢复、鼓种或乐器修正保留原始来源；钢琴/吉他允许改成另一类别或未知。跨来源复核只影响默认派生选择，原始项保留。
- 模型、辅助音频及候选缓存绑定完整歌曲 PCM、分离结果、model/runtime/config 与结果身份；取消、换歌、重新分离、离页和迟到消息通过 generation/job/result 身份隔离，不能覆盖当前状态。恢复必须验证缓存与文件完整性；quota／损坏失败保持人工工程可用。

## 原子应用与当前工程

仅显式应用候选到新标记轨。乐器对应 lane，音高／鼓种对应 inner class，复用 [EditorProjectV2](../editor/project-format-v2.md) 的 point/range 数据，不增加 JSON 字段。应用前完成同类去重、歌曲边界和同 lane/class 的范围重叠校验；一次性发布整个新工程或保持原工程不变。人工标记和 tempoMap 保留。

同一结果／候选应用身份不可重复应用；冲突、旧歌／旧结果、无效候选、超界或范围真重叠必须给出可修正反馈。应用后的事件继续支持现有分类、删除、移动、range 端点、小节操作、草稿恢复和工程导入导出。
