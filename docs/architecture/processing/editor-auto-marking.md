# Editor 分轨试听与有限乐器自动标记

本契约依据 owner 提供的「修订版：Editor 分轨试听与有限乐器自动标记」实施。它授权本轮试听与识别扩展；不改变 EditorProjectV1，不包含 MIDI 导出、P3 节拍追踪、正式 readiness 或发布。当前实现和验证进度须以源码与本项目实际运行记录为准。

## 范围与模型

| 输入与能力 | 固定路线 | 边界 |
| --- | --- | --- |
| 当前 FT drums → kick / snare / hat | ADT_STR ONNX encoder / decoder，Worker WASM，贪心 token 解码 | 使用自定义鼓词表；其他鼓种不强行归入三类。达到解码上限报告截断。 |
| 当前 FT bass、vocals → 音符 | 官方 Basic Pitch ONNX，Worker WASM | 保留音高与音符实际起止，不估计混响或 release 拖尾。 |
| 原曲 PCM → 钢琴、吉他候选 → 音符 | 独立 htdemucs_6s 辅助分析，再逐乐器 Basic Pitch | 只保留钢琴／吉他输出，不同时转写 FT other；乐器身份是待复核候选。 |

FX、Pad、合成器预设区分、复杂 other 与 YourMT3+ 转换／部署留待后续。所有产品处理在浏览器内，不要求 Python、本地服务或外部辅助程序。已有四轨 FT 继续使用原固定模型与 WebGPU 配置，六轨辅助结果不能替代四轨试听。

模型、ORT 部署资产、算法配置、输入／输出 tensor、采样率、频谱、分段、词表与时间偏移共同进入可验证的固定身份。生产 URL 使用 immutable revision；下载校验失败明确报错，不增加静默模型或 provider fallback。ADT_STR 权重及改编按已接受的独立 CC BY-SA 4.0 边界保存上游、转换来源、归因与改编信息；应用代码不因模型卡而被宣称已获任何额外许可。

## 试听 transport

- 四条真实 FT 音轨分别静音，默认全部未静音；统一播放／暂停播放所有未静音轨，提供返回原曲入口。鼓种只是标记类别，不新增鼓内音源分离或 kick/snare/hat 静音。
- 复用唯一 AudioEngine 的 AudioContext、播放时钟、暂停、seek、总音量、结束和 Editor repeat-one 策略。原曲／FT／辅助乐器切换保留当前原曲绝对秒数。PlaybackSnapshot 明确提供当前试听来源与等待／读取错误。
- 初始 PCM 块约四秒、提前准备八秒；使用有界文件读取与节点调度，不整体解码或驻留四条长音轨。读取未就绪／失败必须停止有效播放时钟推进并显示状态，不能让游标继续前进而没有音频。
- 钢琴／吉他候选复用同一 transport 试听辅助音频。切回标记工作区保留试听；换歌、确认离开 Editor、清理相关缓存或 dispose 结束读取与试听租约，返回原曲并释放节点、buffer、监听及文件引用。

## 分析、候选与身份

- 分轨选择决定任务；phase、已完成单位、总单位与 elapsed 来自真实下载、预处理、推断、解码和写入。没有总单位的初始化阶段保持不定进度，不捏造整体百分比。
- 辅助六轨分析从原曲 PCM 开始，分段 overlap-add 后只将钢琴／吉他分块写入 OPFS；释放六轨 session／输出 tensor 后逐乐器转写，不能让所有模型和全曲音轨同时驻留内存。
- 统一候选保留稳定 ID、原曲起止秒数、音高或鼓种、乐器候选、强度、模型／算法／歌曲／分离结果来源身份。短音的底层结束时间仍保留；默认逐轨 300ms 分界，调整分界只重分类现有候选，不重跑模型。
- drums 输出 point；同刻不同鼓种可以并存，仅去除同类别重复事件。音符 range 表示单个音符持续时间，不表示小节或整段乐器活动。所有自动结果保留实际时间，不自动吸附网格。
- 类别筛选、候选删除与鼓种／乐器人工改类均作用于候选；钢琴／吉他允许改为另一类别或未知。跨乐器疑似重复显示供复核，不能自动删除。
- 模型、辅助音频及候选缓存绑定完整歌曲 PCM、分离结果、model/runtime/config 与结果身份；取消、换歌、重新分离、离页和迟到消息通过 generation/job/result 身份隔离，不能覆盖当前状态。恢复必须验证缓存与文件完整性；quota／损坏失败保持人工工程可用。

## 原子应用与 V1

仅显式应用候选到新标记轨。乐器对应 lane，音高／鼓种对应 inner class，复用 EditorProjectV1 的 point/range 数据，不增加 JSON 字段。应用前完成同类去重、歌曲边界和同 lane/class 的范围重叠校验；一次性发布整个新工程或保持原工程不变。人工标记和 tempoMap 保留。

同一结果／候选应用身份不可重复应用；冲突、旧歌／旧结果、无效候选、超界或范围真重叠必须给出可修正反馈。应用后的事件继续支持现有分类、删除、移动、range 端点、小节操作、草稿恢复和工程导入导出。
