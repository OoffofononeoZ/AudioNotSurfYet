# 按实际影响验证

| 范围 | 必要证据 |
| --- | --- |
| Brief | V2 成功/缺项/未知字段，旧版本拒绝，preset 拒绝 new，existing 精确引用，CLI 零写入 |
| 文件夹 | 信息、路径、预览、源码入口、依赖、重复身份和损坏文件拒绝；--check 只读 |
| 元素 | 可封装、哈希稳定、完整参数/default bindings、隔离初始化、真实 Shader 编译 |
| 预设 | 无算法/元素，依赖精确；重复实例 UUID/目标隔离；共同值/差异/重新应用 |
| 输入 | 静态/静音/低/高、向量/单位、四特征并集、loading/error/unbound 和导出阻断 |
| 确定性 | seed/绝对时间、多次 seek、逐帧/跳转与历史重建一致 |
| 生命周期 | resize/context recovery、取消/迟到/离页、算法及 GPU 释放 |
| 工程和输出 | V5 自包含往返、断开库恢复、Chrome/Edge 预览及短离线 WebM |

封装器检查 schema、身份、依赖和模块自包含语法，不在 Node 主进程执行资源代码。算法初始化、GPU、视觉/像素、性能和媒体须在宿主浏览器隔离环境验证；未具备环境时报告未运行。
