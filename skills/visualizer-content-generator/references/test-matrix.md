# 内容生成验证

## Skill 与输入校验器

`npm run test:skill:visualizer-content-generator` 验证：

- 静态新元素无需动态 binding；Analyzer scalar/vector 和 native frequency/waveform 的完整语义可接受。
- 纯复用预设、含新增类型的预设、modifier 和 transition（含显式 unbound）可表达。
- 缺失意图、新元素结构/运动、绑定映射/响应/时间、向量分配或积分边界时返回对应路径。
- 非法类型/枚举、未知字段、旧 brief、Editor source、重复 key、悬空/重复目标、效果引用效果和非法时间种类被拒绝。
- CLI 缺少/多余参数、不可读文件、损坏 JSON 返回 exit 2；有效输入返回 exit 0。成功与失败不改输入、不生成文件；import 纯校验函数不执行 CLI。

人工路由演练覆盖“新增静态元素”“仅复用元素做 PV 预设”“含新元素的完整场景”“原生波形驱动元素”“修正已有预设”。核对正确选路、必要输入询问、注册可行性检查和合同批准前零仓库写入。不以逐字匹配文档标题来证明 agent 行为。

## 按具体 Content Contract 选择

| 变化 | 必要验证 |
| --- | --- |
| 新元素/参数 | descriptor 完整性、默认值/编辑精度、允许来源；静态或低/高/静音映射、参数隔离和非法输入行为 |
| 新预设 | V4 组、子元素顺序/时长/引用、多次添加身份隔离、共同参数批量写入/差异/重新应用、隐藏与删除清理，已有元素不变 |
| 工程/输入 | strict V4 往返与内嵌资源恢复，未知字段/内核/哈希/归属拒绝；全工程 4/5 特征边界、有效启用集合、native 不计额度、失败原子保留工程 |
| 资源包 | 请求与磁盘导入、精确依赖、重复/冲突/新版本、IndexedDB 失败与刷新、移除后已有工程仍可恢复；哈希封装只证明身份一致 |
| 效果/转场 | 目标限定、删除引用清理、空目标/unbound 的草稿与导出行为、范围刷新、终值保持及重叠接管 |
| 时间/状态 | 同工程/seed/时间在连续播放、seek、暂停、刷新与离线帧求值中一致；仅对实际存在的状态检查 checkpoint/失效 |
| 渲染/资源 | 真实 GPU 静态/低高画面、参数编辑、目标隔离；单宿主、resize/DPR/全屏、context recovery、重复添加删除/离页与幂等释放 |
| 离线输出 | 同一 renderer 手动租约、所需历史输入准备、取消/迟到结果及恢复预览；选择受影响输出档位做实际 WebM 解码、帧数/PTS/同步检查 |

浏览器使用当前支持的 Chrome/Edge 和适用视口，不扩展支持矩阵。仅复用已有元素的预设重点检查新增组合、真实画面和短导出，不自动重跑全套输入算法或长曲矩阵。新增状态/输入/资源路径按风险补邻接专项；不默认累计 V1–V6、正式 canonical 或 readiness。

先核对 package.json、tests README 与相邻现行测试，优先复用 composition/presets/native-input/offline-export 的测试入口，不引用退役命令。校验器/文档本身的修改运行 skill 专项、元数据、test:tools、test:docs 和交付检查，不要求产品浏览器或构建。

## Fixture 与结论

优先复用现有确定性 fixture 和 Editor 快照。必要新资产需说明生成方法、许可与 SHA-256；大型音频/WebM/trace 留在本地忽略产物目录。截图只是视觉参考，不自动成为运行时资产。

通过、失败、未运行分别报告。环境受限注明原因；不得把产品错误记为 unavailable，不编造人工视觉/试听/OS 保存或性能证据。日常内容验证不继承历史 canonical，不产生整体 readiness 或发布结论；正式评审只在另有明确任务时开展。
